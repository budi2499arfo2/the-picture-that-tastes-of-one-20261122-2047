One perfect ripe strawberry, drawn entirely in code: glossy red body with
seed dimples, water droplets, a soft specular highlight, and a fan of fresh
green leaves on a warm cream background. No photo, no downloaded assets —
every pixel is painted by the program at run time.

## Run it

```sh
python3 main.py
```

Writes the picture to `$MAKEFUN_OUTPUT_DIR/entry.png` (default
`/output/entry.png`): a 1024×1024 PNG under 1 MB. Python 3 standard library
only — no dependencies, no network.
